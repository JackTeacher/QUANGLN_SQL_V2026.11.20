Sổ Tay Hướng Dẫn Sử Dụng Toàn Diện

Tài liệu chuẩn hóa dành cho Kỹ sư CNTT, Quản trị viên cơ sở dữ liệu (DBA) và Chuyên viên triển khai hệ thống thông tin bệnh viện (HIS/LIS/PACS).

🏷️ Phiên bản: V2026.11.20 📅 Ngày phát hành: 20/11/2026 ✍️ Tác giả: Lương Ngọc Quảng

1. Màn hình Tổng quan (Dashboard)

Màn hình trung tâm hiển thị chỉ số sức khỏe hạ tầng cơ sở dữ liệu và truy cập nhanh vào mọi phân hệ của phần mềm.

Các khối tính năng nổi bật:

  • Thanh Lối Tắt Truy Cập Nhanh (Quick Launch Bar): Nút bấm chuyển nhanh chỉ với 1-Click tới Trình soạn SQL, Trợ lý tra lỗi (RAG), Trợ lý AI SQL Partner, Khám phá dữ liệu, Thiết kế truy vấn, Kết nối CSDL, Nhật ký kiểm toán và nút ↻ Làm mới số liệu.
  • Thống kê thời gian thực: Đo lường số lượng kết nối đã lưu, kết nối đang hoạt động, tổng truy vấn, tỷ lệ thành công (Success Rate), thời gian phản hồi trung bình (ms) và biểu đồ phân bổ hệ quản trị CSDL.
  • Kết nối Đánh dấu Yêu thích: Hiển thị các hồ sơ kết nối hay dùng kèm nút thao tác trực tiếp 📝 SQL (mở ngay trong Trình soạn SQL) và 🔍 Duyệt (mở ngay trong Khám phá dữ liệu).
  • Hoạt động truy vấn gần đây: Hiển thị trực quan trạng thái ✔ Thành công / ✖ Thất bại cùng nút 📝 Mở SQL trên từng dòng để nạp lại câu lệnh vào Trình soạn SQL.
  • Thanh điều hướng co giãn (Collapsible Sidebar): Nhấn nút ☰ để mở rộng hoặc thu gọn thanh menu sang dạng biểu tượng tinh gọn, tối đa hóa diện tích làm việc.

2. Quản lý Kết nối Cơ sở Dữ liệu

Hỗ trợ đầy đủ các hệ quản trị CSDL phổ biến nhất trong ngành Y tế và Doanh nghiệp.

Hệ Quản Trị Cổng Mặc Định Đặc Thù Trong Hệ Thống Y Tế (HIS)
Oracle Database 1521 Cơ sở dữ liệu lõi của phần lớn các hệ thống HIS bệnh viện hạng 1, tuyến TW (hỗ trợ SID / Service Name / Wallet).
Microsoft SQL Server 1433 Rất phổ biến trong các hệ thống LIS xét nghiệm, PACS chẩn đoán hình ảnh và phân hệ viện phí.
PostgreSQL 5432 CSDL nguồn mở hiện đại, hiệu năng cao, thường dùng cho cổng trung gian BHYT và bệnh án điện tử EMR.
MySQL / MariaDB 3306 Ứng dụng cho các web portal bệnh nhân, đăng ký khám bệnh online, kiosk tiếp đón.
SQLite Tệp cục bộ CSDL nhúng độc lập, dùng để test dữ liệu offline, kiểm thử quy trình.
🛡️ Bảo mật DPAPI & Phân quyền 3 cấp: Mật khẩu kết nối CSDL được mã hóa tự động bằng công nghệ Windows DPAPI theo tài khoản Windows hiện tại. Hỗ trợ 3 chế độ an toàn: Chỉ đọc (Read-Only), Đọc và ghi (Read-Write) và Quản trị (Administrative).
Thao tác nhanh:
  • Nhấn ⭐ Yêu thích để ghim kết nối hay dùng lên đầu danh sách và Dashboard.
  • Chuột phải vào kết nối để Nhân bản, Kiểm tra kết nối, hoặc Mở thẳng trong Trình soạn SQL.
  • Hỗ trợ Xuất Excel (.xlsx) và Sao lưu / Khôi phục JSON toàn bộ danh sách kết nối (không kèm mật khẩu).

3. Trình Soạn Thảo & Thực Thi SQL (Chuẩn IDE)

Không gian làm việc trung tâm chuyên nghiệp tương đương DataGrip/DBeaver dành cho soạn thảo script, chạy truy vấn thông minh, phân tích kết quả và quản lý giao dịch an toàn.

Các tính năng nâng cao tại phiên bản V2026.11.20:

  • Thước đánh số dòng chuyên dụng (Line Numbers Gutter): Cột số dòng hiển thị bên trái khung code, đồng bộ 100% khi cuộn dọc, tự động mở rộng theo số chữ số và cho phép nhấp vào số dòng để nhảy con trỏ tới dòng đó.
  • Thực thi câu lệnh thông minh (Ctrl + Enter & nút ▶ Chạy câu hiện tại): Tự động cô lập và chỉ thực thi riêng câu lệnh mà con trỏ chuột đang đứng (hoặc đoạn bôi đen), không ảnh hưởng tới các câu khác trong cùng tab. Phím F5 chạy toàn bộ script.
  • Thanh công cụ Tìm kiếm & Thay thế nổi (Ctrl + F / Ctrl + H): Hỗ trợ F3 (tìm kế tiếp), Shift + F3 (tìm lùi), nút Aa (phân biệt hoa/thường), đếm tổng số vị trí trùng khớp, Thay thế và Thay thế tất cả.
  • Thanh trạng thái con trỏ & Thu phóng (Status Bar): Hiển thị thời gian thực tọa độ Dòng X, Cột Y, Tổng cộng: N dòng, Đã chọn: Z ký tự cùng bộ nút phóng to/thu nhỏ cỡ chữ (A- / A+ / ↺ hoặc Ctrl + Lăn chuột).
  • Quản lý Đa Tab nâng cao: Nhấp đúp chuột vào tiêu đề tab để đổi tên trực tiếp tại chỗ (Enter lưu, Esc hủy); Menu chuột phải trên tab hỗ trợ: Đổi tên, Nhân đôi tab, Sao chép toàn bộ SQL, Lưu tab, Đóng các tab khác, Đóng các tab bên phải, Đóng tất cả.
  • Gợi ý thông minh theo ngữ cảnh (IntelliSense Ctrl + Space):
    • Sau FROM / JOIN / INTO / UPDATE: Gợi ý danh sách Bảng và View thuộc Schema đang kết nối.
    • Sau WHERE / SET / ON / GROUP BY / ORDER BY / dấu chấm (t.): Chỉ gợi ý duy nhất các cột của bảng trong câu lệnh hiện tại, tự động cô lập theo từng câu lệnh và loại bỏ hoàn toàn tên bảng gây nhiễu.
  • Kho ⚡ Mẫu SQL ▾ với 8 nhóm chuyên biệt (40+ mẫu): Bao gồm Truy vấn SELECT, Kết hợp JOIN, Thống kê & Window Functions, Bảng tạm WITH CTE & Đệ quy, Chuyên ngành Y tế & HIS (HIS_PATIENT, HIS_SERE_SERV, HIS_EXP_MEST, lọc thời gian 14 số yyyyMMddHHmmss, cờ hiệu lực IS_ACTIVE=1, IS_DELETE=0), Thao tác DML, Cấu trúc DDL, và Tiện ích Ngày giờ & Chuỗi.
  • Bộ nút DML Đa Năng & Transaction: Sinh nhanh câu lệnh INSERT / UPDATE / DELETE đơn hoặc hàng loạt (Batch, CASE WHEN, Xóa mềm HIS) và kiểm soát giao dịch (Bắt đầu Transaction, COMMIT, ROLLBACK).
  • Đo lường hiệu năng & Xuất kết quả: Hiển thị ⏱ Thời gian (ms), ⚡ Tốc độ (dòng/giây), lọc theo cột độc lập và xuất ra Excel (.xlsx), CSV, Markdown Table, JSON Array, INSERT Statements.

4. Sơ Đồ Trực Quan (ER Schema Diagram)

Tự động phân tích và vẽ sơ đồ liên kết các bảng ngay khi chọn Schema, đồng thời hỗ trợ kéo-nối quan hệ JOIN và sinh câu SQL chuẩn xác.

  • Tự động vẽ sơ đồ ngay khi chọn Schema: Ngay khi bạn chọn kết nối và Schema, hệ thống tự động nạp cấu trúc các bảng, phát hiện các khóa liên kết (ví dụ: TREATMENT_ID → HIS_TREATMENT.ID, PATIENT_ID → HIS_PATIENT.ID, TDL_..._ID) và tự động kẻ đường nối quan hệ giữa các bảng trên sơ đồ.
  • Lọc nhóm bảng & Điều chỉnh mật độ: Nhập từ khóa vào ô 🔍 Lọc nhóm bảng trên sơ đồ (ví dụ: EXP_MEST, TREATMENT) rồi nhấn Enter hoặc 🔄 Vẽ lại sơ đồ Schema để chỉ vẽ riêng cụm bảng liên quan; Tùy chỉnh số bảng (6 bảng, 12 bảng, 24 bảng, 50 bảng, 100 bảng, hoặc Tất cả toàn bộ Schema).
  • Chọn cột & Thiết lập quan hệ JOIN: Hỗ trợ nút ☑ Tất cả trên từng thẻ bảng, bổ sung/chỉnh sửa quan hệ JOIN (INNER, LEFT, RIGHT, FULL) và nhập điều kiện lọc WHERE.
  • Xuất ảnh .PNG, Lưu sơ đồ & Báo cáo: Hỗ trợ bấm 🖼️ Lưu ảnh (.PNG) để xuất toàn bộ sơ đồ thành tệp hình ảnh sắc nét, lưu sơ đồ ra tệp JSON, xuất danh sách bảng/cột ra Excel (.xlsx), bấm 📋 Sao chép SQL hoặc 📥 Chèn vào SQL Editor.

5. Khám Phá Dữ Liệu & Từ Điển Bảng

Duyệt cấu trúc schema, xem dữ liệu bảng/view, thêm/sửa/xóa dòng trực tiếp có kiểm soát khóa chính và sinh mã DDL tạo bảng.

5 Tab Nghiệp Vụ Chuyên Sâu:

  1. Tab 1 - Dữ liệu bảng:
    • Phân trang linh hoạt (50, 100, 200, 500, 1.000 dòng) và lọc dữ liệu theo từng cột hoặc toàn bảng.
    • Nút ➕ Thêm dòng (tự động điền sẵn IS_ACTIVE=1, IS_DELETE=0 nếu có), chỉnh sửa trực tiếp trên ô lưới và nhấn 💾 Lưu thay đổi để ghi nhận an toàn trong Transaction.
    • Nút 📋 Copy INSERT, 📋 Copy JSON, xuất Excel (.xlsx) và CSV UTF-8.
  2. Tab 2 - Cấu trúc cột (Data Dictionary): Xem danh sách cột, kiểu dữ liệu, Nullable, Khóa chính (PK), Default và Ghi chú. Bổ sung nút 📋 Copy danh sách tên cột và nút 📊 Xuất từ điển cột ra Excel.
  3. Tab 3 - Thông tin & Thống kê: Xem tổng số dòng, số lượng cột, cột khóa chính và thuộc tính bảng.
  4. Tab 4 - SQL Mẫu (10 mẫu tự động): Tự động sinh câu lệnh theo cấu trúc cột thực của bảng: SELECT dữ liệu, Đếm COUNT(*), Thống kê GROUP BY & COUNT, Kiểm tra dữ liệu trùng lặp, Tìm bản ghi mới nhất (Top 50), INSERT, Batch INSERT, UPDATE, Xóa mềm HIS (IS_DELETE = 1), DELETE.
  5. Tab 5 - 📄 DDL Tạo bảng: Tự động sinh cú pháp CREATE TABLE trọn vẹn (kèm Primary Key và Comments) theo đúng chuẩn hệ quản trị đang kết nối.

6. Trợ Lý AI · SQL Partner

Hỗ trợ chuyển đổi ngôn ngữ tự nhiên thành SQL, tối ưu hiệu năng truy vấn, giải thích giải thuật và kiểm tra bảo mật SQL.

  • Chế độ ⚡ Chuyên gia SQL Nội bộ (Offline - Không cần Key): Hoạt động 100% cục bộ ngay lập tức mà không cần API Key, tự động tương thích phương ngữ CSDL đang chọn (Oracle, PostgreSQL, SQL Server, MySQL, SQLite) cho các kịch bản:
    • Báo cáo Y tế / HIS: Lượt khám ngoại/nội trú theo khoa, bệnh nhân tái khám, đơn thuốc kháng sinh, viện phí BHYT, chỉ định CLS chưa có kết quả, nội trú dài ngày.
    • Tối ưu DBA: Phân tích điểm nghẽn & gợi ý Index, chuyển Subquery sang WITH CTE, kiểm tra SQL Injection & Parameterized Query, sinh dữ liệu mẫu Mock Data và giải thích chi tiết câu SQL.
  • Nhóm AI KHÔNG CẦN API KEY (Dùng ngay miễn phí):
    • ⚡ Chuyên gia SQL Nội bộ: Chạy 100% offline ngay trên máy, không cần Internet, bảo mật dữ liệu bệnh viện.
    • 🌐 Pollinations AI · GPT-OSS 20B: Cloud miễn phí hoàn toàn không cần Key (https://text.pollinations.ai/openai, model openai).
    • AI Local trên máy cá nhân: Hỗ trợ sẵn cấu hình cổng cho 🦙 Ollama (cổng 11434), 🖥️ LM Studio (cổng 1234), ⚡ Jan AI (cổng 1337) và 🚀 llama.cpp / LocalAI (cổng 8080).
  • Nhóm Cloud AI cần API Key & Bảo mật phiên: Kết nối linh hoạt với Google Gemini, Groq (tốc độ cao, có gói free), DeepSeek, OpenAI (ChatGPT) hoặc Tùy biến (OpenRouter, vLLM, proxy nội bộ). API Key chỉ lưu trong RAM của phiên làm việc, không lưu ra ổ đĩa.
  • Liên thông tức thì với Workspace: Bấm 📥 Chèn vào SQL Editor hoặc ▶ Chạy ngay để tự động chuyển sang Trình soạn SQL và thực thi. Hỗ trợ xuất toàn bộ hội thoại ra Excel (.xlsx).

7. Trợ Lý Tra Lỗi & Cẩm Nang Tri Thức (RAG Skill Assistant)

Trung tâm hỗ trợ kỹ thuật và tra cứu sự cố thông minh, tự động quét sâu các tài liệu Word (.docx), file SQL, văn bản nghiệp vụ nạp từ máy tính cá nhân để tìm ra chính xác nguyên nhân và giải pháp sửa lỗi.

Các tính năng cốt lõi:

  • Nạp tài liệu kỹ năng đa định dạng: Hỗ trợ nạp tệp đơn hoặc nạp nguyên thư mục từ máy tính: Word (.docx), kịch bản SQL (.sql), tệp văn bản (.txt, .md, .log, .json, .csv).
  • Quét sâu & Phân tách mục thông minh:
    • Đọc sâu tệp Word .docx bảo toàn từng đoạn văn và bảng biểu.
    • Tự động bóc tách các danh sách mẹo/câu lệnh đánh số liên tiếp (1. , 2. , 102. ) thành từng mục độc lập, trích xuất đúng giải pháp cần tìm và loại bỏ hoàn toàn các nội dung thừa gây rối mắt.
  • Trích xuất câu lệnh SQL 1-Click: Tự động tách mã SQL vào khung chuyên dụng kèm nút 📥 Chèn vào Trình soạn SQL.
  • Tab "Lịch sử hỏi" & Giao tiếp thân thiện: Lưu lại mọi câu hỏi kèm mốc thời gian để chạy lại với 1 click; phản hồi bằng giọng điệu tự nhiên, gần gũi, nhận diện chào hỏi hàng ngày.
  • Bảo mật kép: Mặc định chạy 100% Offline trên máy cục bộ, có tùy chọn kết nối Online AI khi cần suy luận nâng cao và xuất hội thoại ra file Markdown (.md).

8. Lịch Sử Truy Vấn (Query History)

Tự động lưu lại tất cả các câu lệnh SQL đã thực thi (mã hóa bằng Windows DPAPI) cùng trạng thái thành công/lỗi, thời gian chạy, số dòng và IP máy trạm.

  • Tìm kiếm nhanh theo từ khóa trong SQL, kết nối, người dùng hoặc IP máy trạm; lọc theo trạng thái và khoảng thời gian (Hôm nay, 7 ngày, 30 ngày).
  • Hiển thị chi tiết mã lỗi thực tế trong khung Inspector khi câu truy vấn bị thất bại.
  • Nút 🛠️ Tra lỗi (tự động hiển thị khi chọn câu truy vấn bị lỗi) để chuyển thẳng sang Trợ lý tra lỗi (RAG) tìm giải pháp khắc phục.
  • Nút 📝 Mở trong SQL để nạp ngược lại câu lệnh vào Trình soạn SQL; Hỗ trợ xuất toàn bộ lịch sử ra Excel (.xlsx) và CSV.

9. Quản Lý & Kiểm Thử API (API Manager)

Giao diện kiểm thử API RESTful chuẩn Postman dành riêng cho các cổng tích hợp bệnh viện.

  • 6 mẫu API Y tế / HIS tích hợp sẵn: Tra cứu thẻ BHYT (Cổng BHXH), Gửi hồ sơ Giám định XML 130/4210 BHYT, Đồng bộ đơn thuốc quốc gia, Tra cứu Bệnh nhân HL7 FHIR (EMR), Gửi chỉ định Cận lâm sàng LIS/PACS, và Health Check.
  • Hỗ trợ đầy đủ phương thức HTTP (GET, POST, PUT, PATCH, DELETE, HEAD, OPTIONS), xác thực Bearer Token / Basic Auth / API Key.
  • Tự động định dạng JSON (✨ Prettify JSON), đo lường thời gian & dung lượng phản hồi, nút 💾 Lưu tệp xuất Response Body ra .json / .xml / .txt và nút 📋 Sao chép cURL.
  • Tab Lịch sử: Nhấp vào bất kỳ dòng lịch sử gọi API nào để nạp lại ngay Method và URL.

10. Nhật Ký Kiểm Toán (Audit Log & Khôi phục dữ liệu)

Truy vết chặt chẽ mọi hành vi can thiệp thay đổi dữ liệu (INSERT, UPDATE, DELETE) được mã hóa bằng Windows DPAPI nhằm đảm bảo tiêu chuẩn an toàn thông tin y tế.

Khung Chi Tiết 3 Tab Chuyên Sâu:

  • Tab 1 — 📊 Bảng so sánh Trước / Sau (Visual Diff): Đối chiếu trực quan từng cột dữ liệu bị thay đổi kèm nhãn biến động (✏️ Đã sửa, ➕ Thêm mới, 🗑️ Đã xóa).
  • Tab 2 — ↩️ Lệnh SQL Hoàn tác (Rollback / Undo): Tự động sinh câu lệnh SQL khôi phục dữ liệu về nguyên trạng trước khi sửa/xóa (tự động đảo ngược UPDATE, INSERT, DELETE theo khóa chính) kèm nút 📋 Sao chép và 📝 Mở SQL Hoàn tác trong Editor.
  • Tab 3 — 📄 Dữ liệu JSON gốc (DPAPI): Xem toàn bộ dữ liệu snapshot gốc và hỗ trợ xuất báo cáo kiểm toán ra sổ làm việc Excel (.xlsx).

11. Cài Đặt Hệ Thống (Settings)

  • Chủ đề giao diện (Theme): Chuyển đổi linh hoạt giữa giao diện Sáng (Light) và Tối (Dark) chuẩn High-Contrast.
  • Phông chữ & Cỡ chữ Editor: Chọn phông chữ lập trình (Cascadia Code, Consolas...) và bật/tắt gợi ý mã thông minh.
  • Giới hạn dòng hiển thị & Thư mục xuất file: Tùy chỉnh số dòng tải mặc định và thư mục lưu báo cáo Excel/CSV.
  • Nút 📂 Mở thư mục AppData: 1-Click mở trực tiếp thư mục cấu hình và nhật ký tại %LOCALAPPDATA%\DBStudio.
